# CHINO TECH — Site vitrine

Site web vitrine pour CHINO TECH, solutions informatiques à Abomey-Calavi, Bénin.

## Contenu
- `index.html` — page unique du site (HTML/CSS/JS, sans dépendance externe hors polices Google Fonts)
- `assets/` — logos de l'entreprise (SVG)

## Site en ligne
https://chinotech.netlify.app

## Déploiement
Ce dépôt est relié à Netlify pour un déploiement automatique à chaque modification poussée sur la branche principale.
